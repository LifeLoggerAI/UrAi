## Harness defects found

1. **No base-answer preservation.** Guardian was told to resolve every “valid critique” but had no burden of proof, verification threshold, or mechanism to return an earlier answer verbatim.
2. **Mirror was rewarded for finding faults.** Its instruction asked it to identify mistakes but did not make “no defect” the default, encouraging fabricated corrections.
3. **Unstructured critique.** The audit contained no typed defect, confidence, validator result, or exact candidate identity that code could check.
4. **Information bottleneck.** Archivist received 216 output tokens. At least one regression (`state-4`) followed loss of an unchanged field, and several ledgers were truncated or schema-distorted.
5. **Free-form final regeneration.** Guardian generated a third answer instead of choosing between exact candidates, allowing answer and schema drift.
6. **Single stochastic run.** Temperature and seed were not recorded or fixed. Hosted-model variability was not estimated.
7. **Incomplete compute match.** Council used 9,697 more total tokens than self-refinement and had higher latency. Cost was not recorded.
8. **No majority-vote control.** The run compared direct and self-refinement but not a standard multi-sample baseline.

## Implemented response

Council v2 uses four calls under the same aggregate output-token cap:

1. generate and retain a base answer;
2. require a structured challenger to prove a concrete defect;
3. require an independent structured verifier;
4. require a preservation arbiter to choose between exact answers.

Code returns the selected base or candidate verbatim. Replacement requires unanimous `replace` decisions, a shared allowed defect type, concrete evidence, independently verified defect flags, confidence at or above the configured threshold, equivalent candidate answers, and a valid inferred output contract. Malformed, speculative, stylistic, low-confidence, or disagreeing revisions preserve the base.

This is a development-set intervention. Its efficacy must be measured on the 60-task development suite before any untouched holdout is run.
