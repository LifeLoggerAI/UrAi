## P0 sequencing rule

Do not allow P1/P2 art expansion to delay these P0 outcomes:

1. Home reads as a finished world.
2. Orb presence is final-quality and interactive.
3. Sky-to-Galaxy transition is cinematic and stable.
4. Life Map / memory stars are legible and explorable.
5. Memory Bloom / Replay is visually coherent and returns cleanly.
6. Core sound and camera choreography are integrated.
7. No critical manifest path is a placeholder/fallback.

## Daily lock discipline

At the end of each day:

- move approved masters to the correct `03_APPROVED_FINAL` lane;
- export optimized runtime derivatives;
- update manifest/registry only after the runtime asset exists;
- attach QA evidence;
- update the master tracker status and lock columns;
- archive superseded assets rather than deleting provenance.

No deliverable becomes `LOCKED` from appearance alone. Visual QA, technical QA, and experience QA must all pass.
